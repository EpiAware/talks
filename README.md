# EpiAware talks

Conference talk proposals and presentation materials for [EpiAware](https://github.com/EpiAware) projects.

## Structure

```
proposals/          # Abstracts and submission materials
  juliacon-2026/
  ...
presentations/      # Slides, posters, and other materials for accepted talks
  juliacon-2026/
  ...
```

## Who can submit

EpiAware project maintainers and active contributors.
If you are unsure whether you qualify, open an issue to discuss.

## Contributing

1. Create a markdown file in `proposals/{conference}-{year}/` with your title, abstract, talk outline, and metadata.
2. Open a PR for review before submitting.
3. Once a talk is accepted, add presentation materials to `presentations/{conference}-{year}/`.
